# 🧠 Math Puzzle Game in C

![math-game-banner](https://img.shields.io/badge/Math%20Puzzle%20Game-C%20Language-blueviolet?style=for-the-badge)

Сэтгэх чадвар шалгах, хариултыг хугацаанд нь бичих, оноо цуглуулах математик тоглоом!

## 🎮 Тоглоомын тухай

Энэ бол C хэл дээр бүтээгдсэн **Math Puzzle Game** бөгөөд хэрэглэгч 30 секундын дотор математик асуултад хариулах ёстой. Хариулт зөв бол оноо авна, буруу бол амь хасагдана. 3 амьтай, нийт 100 түвшинтэй.

---

## 📜 Дүрэм

- 🔢 Нийт 100 түвшинтэй, 3 амьтай.
- 🔁 10, 20, 30... түвшинд **3 тусгай бодлого** ирнэ.
- ✅ Хялбар бодлого = +1 оноо, Хүнд бодлого = +3 оноо.
- 💡 `!`, `%`, бутархайтай бодлого = оноо 2 дахин нэмэгдэнэ.
- 🎯 Шинэ **record** эвдвэл нэмэлт +50 оноо.
- ⏰ 30 сек хариу өгөөгүй бол "Хугацаа дууссан" гэж тооцно.
- 🆘 `h` гэж бичвэл тусламж гарна.

---

## ⚙️ Ашигласан технологиуд

- 🖥️ C хэл
- ⌨️ `conio.h`, `windows.h` — Windows системд зориулсан оролт, дуу гаргах зориулалттай.
- 📁 `record.txt` — хэрэглэгчийн хамгийн өндөр оноог хадгална.

---

## 🧩 Түвшин ба Асуултууд

- Асуултууд нь:
  - Нэмэх, хасах, үржих, хуваах
  - `%` (modulus), хувь тооцох
  - Бодлогын бүтэц:
    - `a + ? + ? = result`
    - `a / ? - ? = result`
    - `(a * b) / 100 = ?` (бутархай хэлбэртэй)
